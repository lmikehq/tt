# Thrillers Travels Frontend!

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Description

This repository contains the frontend codebase for Thrillers Travels, a comprehensive travel and education platform built with Next.js 13. Thrillers Travels offers a one-stop solution for booking flights, hotels, cars, applying for visas, admission to schools, and accessing country-specific information. The frontend is developed using Next.js, a React framework for building modern web applications.

## Features

- Streamlined flight, hotel, and car booking functionality
- Seamless visa application processing and assistance
- School admission and scholarship application support
- AI-powered chat system for trip planning and personalized recommendations
- Country-specific information provision, including cultural orientation and global job market insights
- User account management and secure payment processing
- Multi-language support and integration with social media platforms

## Technologies Used

- Next.js 13
- React
- Styled component
- TypeScript
- Material UI

## Getting Started

To set up the development environment and run the frontend locally, follow these steps:

1. Clone the repository: `git clone https://github.com/thrillerstravels/tt-client.git`
2. Install the dependencies: `yarn install`
3. Configure the environment variables: Create a `.env` file based on `.env.example` and update the necessary values.
4. Run the development server: `npm run dev`
5. Open the app in your browser at `http://localhost:3000`
